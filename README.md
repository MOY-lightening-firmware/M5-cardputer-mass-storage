M5Stack Cardputer – Mass Storage Mode
This project enables USB Mass Storage functionality on the M5Stack Cardputer, allowing the device to present its SD card to a computer as a standard storage drive. You can upload files, browse SD card contents, and display small images directly from the card.

✨ Features
Upload files to the SD card  
Connect the Cardputer to your computer and transfer files directly onto the SD card.

View files stored on the SD card  
Display a list of files on the Cardputer’s screen.

File transfer support  
Transfer files between your computer and the SD card through USB Mass Storage mode.

Display small images  
Show low‑resolution images stored on the SD card using the Cardputer’s screen.

📦 Requirements
M5Stack Cardputer

microSD card (FAT32 formatted)

USB‑C cable

Arduino IDE or PlatformIO
